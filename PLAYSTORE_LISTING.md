## 5. Release checklist
1. Raise `versionCode` (currently 1) and `versionName` (currently "1.0") in `frontend/android/app/build.gradle` for every new upload.
2. Build a signed **AAB**: Android Studio → Build → Generate Signed Bundle / APK → Android App Bundle.
3. After first upload, copy the **App signing key SHA-1 / SHA-256** from Play Console → App integrity into Firebase (needed for Google login).
4. Create the reviewer test account before submitting.
